# 스피치 발음 카드

영어 단어나 스피치 문장을 입력하면 발음을 들려주고, 직접 읽은 녹음을 단어별로 채점해 주는 발음 연습 도구입니다.
음성 생성과 음성 인식 모두 내 컴퓨터에서 돌아가서 외부 API 키가 필요 없습니다.

## 기능

### 발음 듣기
- 단어나 문장을 입력하고 **발음 듣기**를 누르면 읽어 줍니다.
- **미국식(en-US) / 영국식(en-GB)** 발음을 고를 수 있습니다.
- **느림(0.5배)** 스위치로 천천히 들을 수 있습니다.
- 읽는 동안 지금 읽고 있는 단어가 강조됩니다.
- 로컬 서버가 켜져 있으면 신경망 TTS인 Kokoro로 자연스러운 음성을 만들고, 서버가 없으면 브라우저 내장 음성으로 대신 읽습니다.

### 발음 기호와 쉬운 읽기
- 단어마다 **IPA 발음 기호**와 한국어 사용자용 **쉬운 읽기**(예: `uh`, `ur`, `dh`)를 보여 줍니다.
- 강세가 있는 음절은 굵게, 음절 경계는 `·`로 표시합니다.
- 내장 사전(약 300단어)에 없는 단어는 영어 철자 규칙으로 추정하고, 인터넷이 연결돼 있으면 무료 사전 API(dictionaryapi.dev)에서 발음 기호를 받아 고칩니다.
- 출처가 **추정**으로 표시된 단어는 틀릴 수 있으니 음성으로 한 번 더 확인하세요.

### 입 모양 그림
- 발음 기호(소리 단위)를 누르면 그 소리를 낼 때의 입 모양(입술, 혀, 이)을 그림으로 보여 줍니다.
- 발음을 재생하는 동안에도 소리에 맞춰 입 모양이 바뀝니다.

### 발음 점수
- **녹음 시작**을 누르고 문장을 읽으면 Whisper(faster-whisper)가 받아 적은 뒤 원문과 비교해서 채점합니다.
- 점수 항목:
  | 항목 | 의미 |
  |---|---|
  | 정확도 | 각 단어를 얼마나 또렷하게 발음했는지 |
  | 완성도 | 원문 단어 중 빠뜨리지 않고 읽은 비율 |
  | 유창성 | 중간에 길게 멈추거나(0.6초 이상) 너무 느리게 읽으면 감점 |
  | 종합 | 정확도 60% + 완성도 20% + 유창성 20% |
- 단어별로 **좋음 / 보통 / 부족 / 다른 단어로 들림 / 빠뜨림**을 색으로 표시하고, 실제로 어떻게 들렸는지도 알려 줍니다.

### 단어별 발음 표
- 문장의 단어를 표로 나눠 쉬운 읽기, 발음 기호, 출처, 점수를 한눈에 보여 줍니다.
- 단어 옆 버튼으로 그 단어만 따로 들을 수 있습니다.
- **암기 모드**를 켜면 원문을 가려서 스피치를 외웠는지 확인할 수 있습니다.

### 그 밖의 기능
- 예시 스피치 문장과 최근 검색 목록을 제공합니다.
- 발음 종류, 속도, 암기 모드 설정과 최근 검색은 브라우저에 저장됩니다.

## 실행 방법

[uv](https://docs.astral.sh/uv/)가 설치돼 있어야 합니다.

```bash
./run.sh
```

`run.sh`가 다음을 순서대로 처리합니다.
1. `.venv`가 없으면 Python 3.12 가상환경을 만들고 `requirements.txt`의 패키지를 설치합니다.
2. `models/` 폴더에 Kokoro 모델 파일(`kokoro-v1.0.onnx`, `voices-v1.0.bin`)이 없으면 내려받습니다. 합쳐서 약 350MB입니다.
3. 서버를 켜고 브라우저에서 http://localhost:8000 을 엽니다.

Whisper 모델(`small.en`)은 처음 실행할 때 자동으로 내려받습니다. 모델을 불러오는 동안에는 화면에 로딩 상태가 표시됩니다.

> 마이크 녹음은 보안 정책상 `localhost` 주소에서만 됩니다. `index.html`을 파일로 직접 열면 발음 듣기만 되고 채점은 되지 않습니다.

### 설정

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `WHISPER_MODEL` | `small.en` | 채점에 쓸 Whisper 모델. `base.en`은 더 빠르고, `medium.en`은 더 정확합니다. |
| `PORT` | `8000` | 서버 포트 |

```bash
WHISPER_MODEL=base.en PORT=8080 .venv/bin/python server.py
```

## 구조

```
English_pronunciation/
├── index.html        # 화면 전체 (발음 사전, 쉬운 읽기 변환, 입 모양, 녹음 UI)
├── server.py         # FastAPI 백엔드
├── run.sh            # 설치 + 모델 다운로드 + 실행
├── requirements.txt
└── models/           # Kokoro 모델 파일 (git에 올리지 않음)
```

### API

| 경로 | 설명 |
|---|---|
| `GET /` | `index.html` 제공 |
| `GET /api/health` | 음성 생성(TTS)과 음성 인식(ASR) 모델 준비 상태 |
| `POST /api/tts` | `{ text, accent, slow }`를 받아 WAV 음성 반환. 최근 200개를 캐시합니다. |
| `POST /api/score` | 녹음 파일(`audio`)과 원문(`text`)을 받아 단어별 점수 반환 |

## 사용 기술

- **음성 생성**: [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx) (미국식 `af_heart`, 영국식 `bf_emma` 음성)
- **음성 인식**: [faster-whisper](https://github.com/SYSTRAN/faster-whisper) (CPU, int8)
- **서버**: FastAPI + uvicorn
- **오디오 변환**: PyAV (브라우저 녹음 webm/mp4를 16kHz 모노로 변환)
